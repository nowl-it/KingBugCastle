# King Bug Castle — cách chơi

Bản private server do người hâm mộ làm cho King God Castle. Không liên kết với Awesomepiece.
Chỉ dùng cho mục đích nghiên cứu / tương tác hệ thống.

<sub>🇬🇧 <a href="README_PLAYER.md">Read in English</a></sub>

Bạn nhận được đúng một file: **`KingBugCastle.xapk`**. Địa chỉ server đã được nhúng sẵn —
**không cần root, không sửa hosts, không cấu hình gì**. Nó cài song song với game thật
(package khác: `com.nowl.castle`), nên bạn giữ được cả hai.

## Cài đặt (Android)

1. Cài một app cài APK dạng split từ Play Store — **APKPure** hoặc **SAI (Split APKs Installer)**.
2. Mở `KingBugCastle.xapk` bằng app đó rồi bấm Install. (Với SAI: "Install APKs" → chọn file `.xapk`.)
3. Mở **King Bug Castle**.

Chỉ vậy thôi. Game kết nối tới server của người host — miễn là server của họ đang chạy và
truy cập được, bạn vào thẳng qua màn hình tiêu đề.

> Nếu nó treo ở màn hình loading/patch thì server đang tắt, hoặc địa chỉ đã nhúng không
> truy cập được từ mạng của bạn — hỏi người đã chia sẻ file.

## Lưu ý

- Tiến trình của bạn nằm trên server của **người host**, không phải server Awesomepiece thật.
  Đây là sandbox riêng; mọi thứ bạn làm ở đây không chạm vào tài khoản thật.
- Cập nhật: nếu người host đổi địa chỉ server hoặc ra nội dung mới, họ sẽ đưa bạn một file
  `.xapk` mới — cài đè lên bản cũ.
- Gỡ cài đặt bất cứ lúc nào như một app bình thường; không ảnh hưởng tới King God Castle thật.
